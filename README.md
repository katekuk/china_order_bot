
# 🤖 China Order Bot — Telegram-помощник для заказов из Китая 🇨🇳

Бот помогает пользователям:
- узнать, как оформить заказ с китайских маркетплейсов
- рассчитать стоимость в рублях
- получить информацию о доставке
- отследить курс юаня в реальном времени

---

## 🚀 Как запустить и изменить бота

### 📦 1. Клонируй проект

```bash
git clone https://github.com/kathreen28/china_order_bot.git
cd china_order_bot
```

### ✏️ 2. Внеси изменения в код

Открой файл `bot.py` в редакторе (например, [VS Code](https://code.visualstudio.com))  
Внеси нужные изменения (например, текст сообщений, кнопки, формулы).

Сохрани (`Ctrl + S`).

---

### 🚀 3. Отправь изменения в GitHub

```bash
git add .
git commit -m "Обновила код бота"
git push
```

> 💡 Если GitHub запрашивает логин/пароль — используй [Personal Access Token](https://github.com/settings/tokens).

---

### 🔁 4. Перезапусти бота на Railway

1. Перейди в [https://railway.app](https://railway.app)
2. Зайди в свой проект
3. Открой вкладку **Deployments**
4. Нажми **"Restart Deployment"**

После этого бот будет работать с новым кодом ✅

---

## 📄 Требования

- Python 3.10+
- `aiogram`
- `aiohttp`
- (опционально) `gspread`, если используется Google Sheets

Все зависимости указаны в `requirements.txt`.
